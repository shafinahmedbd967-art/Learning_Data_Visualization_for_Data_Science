## 📓 Notebook Breakdown

### 01 — Matplotlib Basics
Getting started with the most fundamental Python visualization library. Covers line plots, bar charts, scatter plots, customization, and figure formatting.

### 02 — Distribution Plots
Visualizing data distributions using Seaborn — `distplot`, `jointplot`, `rugplot`, and `kdeplot` to understand how data is spread.

### 03 — Categorical Plots
Working with categorical data — `boxplot`, `violinplot`, `stripplot`, `swarmplot`, `barplot`, `countplot`, and `factorplot`.

### 04 — Matrix Plots
Using `heatmap` and `clustermap` to visualize correlations and relationships between multiple variables at once.

### 05 — Regression Plots
Building and visualizing regression relationships in data using Seaborn's `lmplot` and `regplot`.

### 06 — Plotly & Cufflinks
Creating beautiful **interactive** charts that you can zoom, pan, and hover over — using Plotly and Cufflinks with Pandas DataFrames.

### 07 — IPL Capstone Project 🏏
A complete real-world mini project using the IPL dataset (`IPL.csv`). Applies all the visualization techniques learned across the course to extract meaningful cricket insights.
